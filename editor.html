Connexion GitHub

Pour publier les cartes directement sur le dépôt, collez un Personal Access Token (fine-grained) avec la permission Contents : Read and Write limitée au dépôt Maitrelynx-ia/francemaster.

Création : GitHub → Settings → Developer settings → Fine-grained personal access tokens → Generate new token. Sélectionnez uniquement le dépôt francemaster et la permission Contents : Read and Write. Le token reste stocké dans votre navigateur (localStorage) et n'est envoyé qu'à api.github.com.
